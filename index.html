Documentation

JSONCargo Container & Vessel Tracking API gives you real-time shipment and vessel tracking data from the world's major shipping lines. This reference covers every endpoint, parameter, and response field.

Quick Start
Get your API key from the pricing page, then pass it as the x-api-key header in every request.

Authentication

All API requests must include your API key in the request header. You can obtain a key by subscribing to any plan on our pricing page - your key will arrive by email immediately after subscribing.

Header Parameter

x-api-key: YOUR_API_KEY

Common Errors

If you are experiencing issues with your API requests, check the following common causes before reaching out to support.

#
Incorrect Container Number
Make sure the container number includes the four-letter prefix (e.g. ABCD1234567).
≈
Incorrect Shipping Line Name
If tracking a third-party prefix, the shipping line must match the API parameter exactly.
✕
Missing, Invalid or Expired API Key
Verify your API key is included in the x-api-key header and is still active. A request without the header returns 401; a key that does not exist returns 403.
↯
Rate Limit Exceeded
A 429 means the key exceeded its per-minute or monthly quota (type=MINUTE or type=MONTHLY in the title). Retry after the limit window passes, and check usage via the API Key Stats endpoint.
⦸
Expired Subscription
Ensure your subscription is active and your payment method is up to date.
↻
Tracking Data Temporarily Unavailable
A 424 means tracking data for this container or Bill of Lading can't be returned right now. Retry later if the response says "retryable": true.

Error Format

Container and Bill of Lading errors carry three fields: code, a stable machine-readable value to build your logic on; title, a human-readable message; and retryable, which is true if the same request may succeed later and false if it will fail the same way until the input changes. Apart from invalid_request, each code always returns the same title, so match on code, not on the text.

JSON
{
  "error": {
    "code": "upstream_unavailable",
    "title": "Tracking data is temporarily unavailable. Please try again later.",
    "retryable": true
  }
}
codeHTTPRetryableMeaning
invalid_request400NoThe request is malformed: a missing or invalid parameter, or an unsupported shipping line. title explains what to fix.
unknown_resource404NoNo tracking data was found for this number and shipping line.
internal_error500YesAn unexpected error on our side.
content_unavailable424NoTracking data for this request is not available.
upstream_unavailable424YesTracking data is temporarily unavailable. Retry later.

API-key errors (401, 403, 429) can come from any endpoint and contain title only. Errors from the vessel, port and API key endpoints also contain title only.

Still experiencing issues? Contact us at support@jsoncargo.com

Endpoint 10: Get API Key Usage Stats

Check your current plan, total requests, requests used, and requests remaining.

GET https://api.jsoncargo.com/api/v1/api_key/stats

No query parameters required. The response is based on the API key provided in the request header.
